Setup:
1. Both this phone and the laptop must be on the same Wi-Fi.
2. Open this page from the laptop's IP address (e.g., http://192.168.x.x:8000/phone).
3. Tap Start Streaming and grant camera permission.
4. On the dashboard, click Switch to Phone Camera.

HTTPS note: Chrome on Android requires HTTPS for camera access unless opened from localhost. Use a reverse proxy (ngrok, Caddy) for HTTPS, or test over USB with adb port forwarding.
